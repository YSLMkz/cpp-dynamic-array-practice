# Динамический массив на C++

## Часть 1. Класс динамического массива (`int`)

| Задание | Что сделано | Где |
|---|---|---|
| 1 | Хранение указателя и размера, конструктор по размеру (заполняет нулями), деструктор, `print()`, сеттер `set()` с проверкой индекса и промежутка −100…100, геттер `get()` с проверкой индекса | `DynamicArray(size)`, `~DynamicArray()`, `set`, `get`, `print` |
| 2 | Конструктор копирования с глубоким копированием | `DynamicArray(const DynamicArray&)` |
| 3 | Добавление в конец с расширением размера и проверкой промежутка | `pushBack(int)` |
| 4 | Поэлементное сложение/вычитание; размер не меняется, недостающие элементы — нули | `add`, `sub` |

## Часть 2. Исключения

Все проверки из части 1 теперь выбрасывают исключение конкретного типа:

| Ситуация | Исключение | Где бросается |
|---|---|---|
| Не удалось выделить память | `std::bad_alloc` | `allocate()` → конструктор, конструктор копирования, `pushBack` |
| Индекс вне границ массива | `std::out_of_range` | `get`, `set` |
| Значение вне −100…100 | `std::invalid_argument` | `set`, `pushBack`, `add`, `sub` (если результат вышел бы за промежуток) |

Память выделяется через `new (std::nothrow)`, который, как `malloc`, при нехватке памяти возвращает `nullptr`; в этом случае `allocate()` явно бросает `std::bad_alloc`.

Если метод бросил исключение, массив остаётся в прежнем состоянии: в `pushBack` старые данные освобождаются только после успешного выделения нового блока, а `add`/`sub` сначала проверяют все результаты и лишь потом меняют элементы.

В `main` каждое действие выполняется внутри `try` с отдельными `catch` для `std::out_of_range`, `std::invalid_argument`, `std::bad_alloc` и общим `std::exception` в конце — в выводе видно, какой именно тип пойман. Для `std::bad_alloc` создаётся массив размером ~4 эксабайта.

Оператор присваивания пока запрещён (`= delete`) — он реализуется в части 5.

## Структура

```
include/DynamicArray.h   объявление класса
src/DynamicArray.cpp     реализация
src/main.cpp             демонстрация
CMakeLists.txt
```

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o main
./main
```

или через CMake:

```bash
cmake -S . -B build
cmake --build build
./build/main
```
