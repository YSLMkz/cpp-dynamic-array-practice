# Динамический массив на C++

## Часть 1. Класс динамического массива

| Задание | Что сделано | Где |
|---|---|---|
| 1 | Хранение указателя и размера, конструктор по размеру, деструктор, вывод, сеттер с проверкой индекса и промежутка −100…100, геттер с проверкой индекса | `DynamicArray(size)`, `~DynamicArray()`, `set`, `get`, `print` |
| 2 | Конструктор копирования с глубоким копированием | `DynamicArray(const DynamicArray&)` |
| 3 | Добавление в конец с расширением размера и проверкой промежутка | `pushBack` |
| 4 | Поэлементное сложение/вычитание; размер не меняется, недостающие элементы — нули | `add`, `sub` |

## Часть 2. Исключения

| Ситуация | Исключение |
|---|---|
| Не удалось выделить память | `std::bad_alloc` |
| Индекс вне границ массива | `std::out_of_range` |
| Значение вне −100…100 | `std::invalid_argument` |

Если метод бросил исключение, массив остаётся в прежнем состоянии.

## Часть 3. Шаблоны

| Задание | Что сделано |
|---|---|
| 1 | Класс стал шаблоном `DynamicArray<T>`. Проверка промежутка −100…100 выполняется только для целочисленных `T` (`if constexpr (std::is_integral_v<T>)` в `checkValue`); для `double`, `std::string` и т.п. проверяется только индекс. Для беззнаковых целых нижняя граница 0, так как отрицательное значение в них не сохранить. |
| 2 | `operator<<` для вывода массива в поток: `[1, 2, 3]`, строки — в кавычках. `print()` использует его же. |
| 3 | `distance(other)` — евклидово расстояние `sqrt(Σ (a[i] − b[i])²)`. Для нечисловых `T` бросает `std::bad_typeid`, при разных размерах — `std::invalid_argument`. |

Дополнительно:

- шаблон целиком находится в `include/DynamicArray.h` — компилятор должен видеть реализацию шаблона при подстановке типа, поэтому `src/DynamicArray.cpp` удалён;
- `add` работает для любого типа с `operator+` (для `std::string` — конкатенация), `sub` — для типов с `operator-`; недостающие элементы считаются `T{}` (0 для чисел, пустая строка для строк);
- результат `add`/`sub` для целых типов проверяется до приведения обратно к `T`, поэтому, например, у `signed char` 100 + 100 не переполнится незаметно, а вызовет `std::invalid_argument`;
- копирование элементов (например, строк) тоже может бросить исключение — в этом случае выделенная память освобождается, утечки нет.

В `main` показана работа с числовыми (`int`, `unsigned int`, `double`) и нечисловым (`std::string`) типами.

Оператор присваивания пока запрещён (`= delete`) — он реализуется в части 5.

## Структура

```
include/DynamicArray.h   шаблонный класс (объявление и реализация)
src/main.cpp             демонстрация
CMakeLists.txt
```

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o main
./main
```

или через CMake:

```bash
cmake -S . -B build
cmake --build build
./build/main
```
