# Динамический массив на C++

## Часть 1. Класс динамического массива (`int`)

| Задание | Что сделано | Где |
|---|---|---|
| 1 | Хранение указателя и размера, конструктор по размеру (заполняет нулями), деструктор, `print()`, сеттер `set()` с проверкой индекса и промежутка −100…100, геттер `get()` с проверкой индекса | `DynamicArray(size)`, `~DynamicArray()`, `set`, `get`, `print` |
| 2 | Конструктор копирования с глубоким копированием | `DynamicArray(const DynamicArray&)` |
| 3 | Добавление в конец с расширением размера и проверкой промежутка | `pushBack(int)` |
| 4 | Поэлементное сложение/вычитание; размер не меняется, недостающие элементы — нули | `add`, `sub` |

Ошибки в этой части сообщаются через `std::cerr` и возвращаемое значение (`false` у `set`, `pushBack`, `add`, `sub`; `0` у `get`). В части 2 они заменяются исключениями.

Все значения массива всегда лежат в −100…100: если результат `add`/`sub` вышел бы за промежуток, массив остаётся без изменений.

Оператор присваивания пока запрещён (`= delete`) — он реализуется в части 5. Без этого присваивание по умолчанию скопировало бы указатель, и память освободилась бы дважды.

## Структура

```
include/DynamicArray.h   объявление класса
src/DynamicArray.cpp     реализация
src/main.cpp             демонстрация всех заданий
CMakeLists.txt
```

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o main
./main
```

или через CMake:

```bash
cmake -S . -B build
cmake --build build
./build/main
```
